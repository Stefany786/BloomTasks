# 🌸 Bloom Tasks

A cute, pink task manager built with vanilla HTML, CSS, and JavaScript — designed to make staying organized feel a little more rewarding.

**Live demo:** https://stefany786.github.io/BloomTasks/

**Demo login:**
- Username: `BloomTask1`
- Password: `WELCOME`

*(Note: this is a client-side demo login for portfolio purposes only — credentials are stored in the JS file, not a real authentication system.)*

## Features

- Task list with checkboxes, priority levels, categories, and optional due dates/times
- Month calendar sidebar to browse and add tasks for any day, past or future
- Custom categories you can create on the fly
- Confetti celebration when all of a day's tasks are complete
- Three color themes (Pink, Lavender, Mint) that persist across sessions
- Fully responsive, no frameworks or build tools — just HTML/CSS/JS and `localStorage`

## Tech stack

HTML5, CSS3 (custom properties for theming), vanilla JavaScript, `localStorage` for persistence, hosted on GitHub Pages.

## Running locally

Clone the repo and open `login.html` in a browser — no build step or server required.
